# AI Customer Sentiment Analytics Platform

> A production-ready sentiment analysis platform built with FastAPI, Streamlit, PostgreSQL, and Transformer models.

## Status
🚧 Under active development

## Tech Stack
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy
- **Frontend:** Streamlit, Plotly
- **ML:** scikit-learn, HuggingFace Transformers (BERT/RoBERTa)
- **AI:** Google Gemini
- **Infrastructure:** Docker, GitHub Actions
